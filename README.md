# 👋 Olá! Eu sou Alan Brilhante

### 💻 Desenvolvedor Full Stack | Backend

Sou **Bacharel em Sistemas de Informação** e **Especialista em Desenvolvimento Web Full Stack pela UFG**, com experiência no desenvolvimento e manutenção de aplicações web, APIs e sistemas corporativos.

Tenho foco principalmente em **Backend**, trabalhando com **Node.js, NestJS, PHP e Laravel**, além de experiência com React no desenvolvimento de interfaces e integração com APIs.

🚀 Gosto de trabalhar com arquitetura de software, APIs, bancos de dados, mensageria, containers e boas práticas de desenvolvimento.
